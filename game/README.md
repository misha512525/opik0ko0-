# VELMONT HEAT

Браузерная 3D-песочница в жанре «open-world crime sandbox». Вымышленный портовый
город **Порт-Велмонт** (~1×1 км), пять сюжетных миссий, машины, трафик, пешеходы,
полиция с системой розыска, оружие, магазины, радио и смена дня и ночи.

Всё содержимое — процедурное: геометрия из примитивов, текстуры рисуются в
`<canvas>`, звуки и музыка синтезируются через Web Audio API. Внешних ассетов нет.

## Запуск

```bash
cd game
npm install
npm run dev        # http://localhost:5180
npm run build      # проверка типов (tsc) + продакшн-сборка в dist/
npm run preview    # просмотр сборки: http://localhost:4180
```

Нужен Node.js 18+ и браузер с WebGL2 (Chrome, Edge, Firefox, Safari 15+).
Параметр `?quality=low|medium|high` в адресе принудительно задаёт качество графики.

### Автотесты (Playwright)

```bash
npm run build && npm run preview &          # сервер на :4180
node scripts/smoke.mjs http://localhost:4180/ walk      # ходьба, день/ночь
node scripts/smoke.mjs http://localhost:4180/ drive     # вождение, занос, взрыв
node scripts/smoke.mjs http://localhost:4180/ traffic   # трафик, пешеходы, наезд
node scripts/smoke.mjs http://localhost:4180/ combat    # стрельба, розыск, полиция, смерть
node scripts/smoke.mjs http://localhost:4180/ missions  # миссии, магазины, карта, пауза, сохранения
```

Скрипт открывает игру в Chromium (`CHROMIUM_PATH` — путь к браузеру), выполняет
сценарий, сохраняет скриншоты в `screenshots/` и падает, если в консоли есть ошибки
или проверка сценария не прошла. Ожидания в тестах идут по игровому времени, а не по
часам, поэтому они устойчивы к медленному софтверному рендеру.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | движение / газ, тормоз, руль |
| Shift | бег |
| Space | прыжок / ручник (занос) |
| F | сесть в ближайшую машину / выйти |
| ЛКМ | стрельба / удар |
| ПКМ | прицел (плечевая камера, мягкий автоприцел) |
| Колесо, 1–3 | смена оружия |
| R | в машине — следующая радиостанция; пешком — перезарядка |
| E | магазин, покраска, сохранение в убежище |
| M | полноэкранная карта |
| Enter | пропустить реплику диалога |
| Esc | пауза (настройки, сохранение, загрузка) |

## Что есть в игре

- **Город**: сетка 10×9 кварталов, улицы по 2 полосы в каждую сторону с разметкой,
  зебрами и светофорами, тротуары с фонарями и деревьями, центральный парк с фонтаном,
  деловой центр с небоскрёбами, жилые кварталы, промзона с контейнерами, набережная.
- **День и ночь**: небо со звёздами и луной, солнце/луна с тенями, ночью горят окна,
  фонари и фары.
- **Игрок**: ходьба, бег, прыжок, камера мышью с коллизией о стены.
- **Машины**: 5 типов (компакт, седан, спорткар, фургон, полиция) с разными
  характеристиками; аркадная физика с заносом на ручнике; урон → дым → огонь → взрыв.
- **Трафик**: езда по полосам, повороты, светофоры, дистанция, перестроение в соседнюю
  полосу, если путь заблокирован; паника при стрельбе.
- **Пешеходы**: гуляют, переходят улицы, разбегаются от выстрелов, взрывов и машин.
- **Розыск 1–5★**: свидетели, зона поиска, полиция на машинах (таран), пешие копы
  (арест на 1–2★, стрельба с 3★), блокпосты с 4★; звёзды гаснут, если уйти из зоны.
- **Оружие**: кулаки, пистолет, автомат; разброс, отдача, магазины, патроны,
  здоровье и броня.
- **Миссии** (сюжетная цепочка): «Старые долги» (доставка на время), «Хвост» (погоня),
  «Гонка по набережной» (контрольные точки на время), «Горячий груз» (угон и уход от
  полиции), «Финал: причал Кесслера» (бой с охраной и боссом + побег).
- **Экономика**: награды за миссии, деньги с NPC, оружейная (оружие, патроны, броня,
  аптечка), покрасочная (ремонт + сброс розыска, если копы не видят).
- **HUD**: вращающаяся миникарта с маршрутом и зоной поиска, здоровье/броня, деньги,
  звёзды, оружие и патроны, спидометр, задания, таймеры, субтитры; карта на M.
- **Радио**: три процедурные станции (синтвейв, лоу-фай хип-хоп, хаус) + «выкл».
- **Сохранения**: localStorage — деньги, прогресс миссий, позиция, оружие, здоровье,
  время суток; автосохранение после каждой миссии, ручное — в паузе или в убежище (E).

## Архитектура

```
game/src
├── config.ts            все настройки: скорости, урон, трафик, цены, розыск, качество
├── main.ts / Game.ts    точка входа; корень композиции, порядок обновления, состояния
├── core/                Loop (фикс. шаг 60 Гц + интерполяция), Input, Events (шина),
│                        Physics (Rapier), Rng, Settings, Context (реестр сервисов)
├── world/               CityLayout (данные города), CityBuilder (меши/коллайдеры),
│                        BuildingMaterial (окна в шейдере), DayNight, TrafficLights, Textures
├── player/              Player (KinematicCharacterController), CameraRig, HumanModel
├── vehicles/            Vehicle (аркадная модель), VehicleModel, VehicleManager
├── ai/                  Roads/Path (полосы), Traffic, Pedestrians + Crowd (инстансинг),
│                        Police, Hostiles (бой NPC), Driving (руль/газ для ИИ)
├── combat/              Weapons (hitscan, трассеры), Damage (урон, смерть, арест), Wanted
├── missions/            types (шаги), definitions (сюжет), MissionManager, FleeDriver
├── economy/             Economy, Shops, Pickups
├── fx/                  Particles (дым/огонь/искры), Markers (маркеры в мире)
├── audio/               AudioEngine (Web Audio), AudioSystem (SFX), Radio (музыка)
├── ui/                  Hud, MapRenderer (миникарта/карта), Menu (меню/пауза/настройки)
└── save/                SaveSystem (localStorage)
```

**Принципы.**
- *Компонентная структура вместо god-объекта.* Каждая система — отдельный класс со
  своими `fixedUpdate(dt)` / `update(dt)`. `GameContext` — только реестр ссылок без
  логики. Системы общаются через типизированную шину событий (`core/Events.ts`):
  например, `Weapons` публикует `gunshot`, а на него реагируют пешеходы (паника),
  трафик, розыск и звук — ничего не зная друг о друге.
- *Фиксированный шаг физики* (`core/Loop.ts`): логика и Rapier — 60 Гц, рендер —
  с интерполяцией положений игрока и машин.
- *Данные отдельно от визуала*: `CityLayout` — чистые данные (без three.js), из
  которых строятся меши, коллайдеры, граф полос для ИИ, миникарта и миссии.

**Физика: Rapier** (`@dimforge/rapier3d-compat`), а не cannon-es: WASM-движок
быстрее на сотнях статических коллайдеров и десятках динамических тел, в нём есть
готовый `KinematicCharacterController` (ступеньки, скольжение по стенам, привязка к
земле), CCD для быстрых машин и быстрые рейкасты для стрельбы, камеры и видимости.
Машины — динамические тела с вращением только по Y; продольная и боковая скорости
задаются аркадной моделью (сцепление, ручник), а столкновения решает Rapier.

**Производительность.**
- Здания — `InstancedMesh` с шейдерными окнами, разбитые на чанки 4×4 (frustum
  culling по чанку) с `THREE.LOD`: ближний уровень — PBR-материал, тени, детали на
  крышах; дальний — Lambert без деталей и теней.
- Фонари, деревья, светофоры, разметка, скамейки, контейнеры — инстансинг по чанкам.
- Пешеходы и пешие копы — по одному `InstancedMesh` на часть тела (~9 draw calls на
  всю толпу). Машины — один слитый меш кузова + колёса, дальний LOD скрывает детали.
- Трафик и пешеходы спавнятся вокруг игрока вне поля зрения и удаляются вдали.
- Тени — одна directional-карта, «едущая» за игроком; дальность прорисовки, тени,
  плотность трафика и разрешение зависят от пресета качества.
- Типичная сцена: 150–250 draw calls, 200–320 тыс. треугольников.

## Как добавить новую миссию

1. Откройте `src/missions/definitions.ts` и добавьте объект `MissionDef` в массив:
   ```ts
   {
     id: 'm6_heist',
     title: 'Ограбление',
     giver: 'Лу',
     start: p(home.x, home.z),       // где стоит маркер старта
     requires: 'm5_finale',          // после какой миссии доступна
     reward: 2000,
     protect: ['getaway'],           // уничтожение этих машин = провал
     steps: [
       { type: 'dialog', lines: [['Лу', 'Есть новое дело…']] },
       { type: 'spawnVehicle', key: 'getaway', vehicle: 'sports', at: p(X[3], Z[2] + 5.25), yaw: Math.PI / 2 },
       { type: 'enterVehicle', key: 'getaway', text: 'Сядь в машину' },
       { type: 'timeLimit', seconds: 90, reason: 'Опоздал' },
       { type: 'goto', at: p(X[6], Z[1]), radius: 8, vehicle: 'getaway', text: 'Езжай к банку' },
       { type: 'setWanted', stars: 2 },
       { type: 'loseWanted', text: 'Оторвись от полиции' },
     ],
     outro: [['Лу', 'Чистая работа.']],
   }
   ```
2. Доступные шаги описаны в `src/missions/types.ts`: `dialog`, `spawnVehicle`,
   `enterVehicle`, `enterAnyVehicle`, `goto`, `timeLimit`, `clearTimer`, `chase`,
   `pickup`, `checkpoints`, `setWanted`, `loseWanted`, `spawnEnemies`, `killGroup`, `give`.
3. Если нужен новый тип шага — добавьте его в union `Step` и обработку в
   `MissionManager.enter()` (мгновенные действия) и `MissionManager.check()` (условие
   выполнения). Маркеры и значки на карте задаются в `markers()` / `blips()`.

Координаты удобно брать из сетки: `X[i]`, `Z[j]` — оси улиц, `+5.25` — внешняя полоса.

## Как добавить новую машину

1. В `src/config.ts` добавьте id в тип `VehicleTypeId` и описание в
   `CONFIG.vehicles.types`: габариты (`half`), масса, макс. скорость, ускорение,
   тормоз, сцепление, сцепление на ручнике, угол руля, колёсная база, радиус колеса,
   прочность, палитра цветов и вес появления в трафике (`trafficWeight`, 0 — не
   появляется в трафике).
2. Внешний вид строится автоматически по габаритам в `src/vehicles/VehicleModel.ts`
   (`bodyGeometry`). Для особого силуэта добавьте ветку по `spec.id`, как у фургона
   или спорткара.
3. Машина сразу появится в трафике и на парковках; для миссий используйте её id в
   шагах `spawnVehicle` / `chase`.

## Настройки баланса

Все числа — в `src/config.ts`: скорость ходьбы/бега, урон оружия и цены, пороги
звёзд розыска и «стоимость» каждого преступления, радиусы зоны поиска и время ухода,
плотность трафика и пешеходов, параметры машин, длина суток, пресеты качества.
