# Фото для сайта: промты для ChatGPT

На сайте 5 мест под фото. Сгенерируйте картинку, сохраните под нужным именем в `src/assets/photos/`
(подходит `.jpg`, `.png` или `.webp`) и пересоберите сайт (`npm run build`). Нет файла — блока на сайте
нет, вёрстка не ломается. Сжатие в AVIF/WebP и нужные размеры сайт делает сам.

Генерируйте все кадры **в одном чате**: сначала вставьте общий стиль, потом по очереди промты.
После каждой картинки можно писать «следующий кадр в том же стиле и свете».

## 1. Общий стиль — вставить первым сообщением

```
Я сделаю серию из 5 фотографий для сайта репетитора по русскому языку и литературе. Все кадры — в одном стиле:

— реалистичная фотография, не иллюстрация и не 3D; как снято на плёночную камеру 35 мм, лёгкое зерно, неглубокая резкость;
— мягкий естественный утренний свет из окна слева, без жёстких теней;
— палитра: светлое дерево, бежевый, кремовый, нежный серо-голубой, немного тёмно-синего, немного живой зелени;
— спокойная минималистичная композиция, много свободного места, 3–6 предметов, без беспорядка;
— в кадре нет людей, лиц и рук;
— нигде нет читаемого текста, букв, цифр, логотипов и водяных знаков: страницы книг и тетрадей пустые или размыты, корешки без надписей;
— не глянцевая стоковая картинка, а живой кадр, как из журнала об интерьере.

Подтверди, и я пришлю первый кадр.
```

## 2. Кадры

### `desk.jpg` — широкая фотография после блока с цифрами

Формат: **горизонтальный 3:2**. На компьютере кадр обрежется в длинную полосу 21:9, на телефоне — в 4:5,
поэтому всё главное — в центре.

```
Кадр 1, горизонтальный 3:2. Светлый деревянный стол, вид сверху под углом около 45°. В центре — раскрытая толстая книга, рядом тетрадь в голубую клетку, синяя ручка и красная ручка, стопка из двух книг в тканевых обложках (тёмно-синяя и бежевая), керамическая кружка с чаем, веточка эвкалипта. Все предметы собраны в центральной горизонтальной полосе кадра, сверху и снизу — свободное дерево стола.
```

### `books.jpg` — рядом с цитатой «70% жизни — репетиторство» (блок «Об Анне»)

Формат: **вертикальный 2:3**.

```
Кадр 2, вертикальный 2:3. Фрагмент светлого деревянного стеллажа: ряд старых книг в тканевых переплётах — тёмно-синие, бежевые и приглушённо-зелёные корешки без надписей, между страницами торчат бумажные закладки. На полке — маленький горшок с растением и чёрная настольная лампа с абажуром. За стеллажом — серо-голубая стена. Тёплый мягкий свет.
```

### `lesson.jpg` — блок «Как мы будем работать»

Формат: **горизонтальный 3:2**.

```
Кадр 3, горизонтальный 3:2. Рабочее место для онлайн-занятия: ноутбук с тёмным выключенным экраном, накладные наушники, раскрытая тетрадь в клетку с размытым нечитаемым конспектом, стакан с карандашами, небольшое растение. Светлый деревянный стол, серо-голубая стена, утренний свет.
```

### `papers.jpg` — карточка «Бесплатно — в канале» (блок «Материалы»)

Формат: **горизонтальный 3:2**.

```
Кадр 4, горизонтальный 3:2. Вид сверху: на светлом деревянном столе стопка распечатанных листов A4 с заданиями (текст мелкий, размытый и нечитаемый), листы скреплены чёрными канцелярскими зажимами. Рядом — карандаш, жёлтый текстовыделитель и красная ручка. Слева край раскрытой тетради в клетку.
```

### `calm.jpg` — рядом с «Частыми вопросами»

Формат: **горизонтальный 3:2** (на сайте обрежется до 4:3).

```
Кадр 5, горизонтальный 3:2. Широкий подоконник утром: чашка чая на блюдце, раскрытая тетрадь с пустыми страницами, карандаш. За окном — мягко размытый город без узнаваемых зданий, лёгкий белый тюль. Спокойное, тихое настроение.
```

## 3. Чего не генерировать

- **Анну.** Сгенерированное «фото» реального человека на её же сайте — подделка. Лучше 2–3 настоящих
  кадра с той же съёмки, что и главное фото.
- **Учеников, их работы с баллами, скриншоты отзывов или результатов.** Сайт держится на фразе «Не верьте
  на слово — проверьте»: одна выдуманная картинка с «100 баллами» обесценит всё остальное.
- **Текст на картинках.** ChatGPT пишет кириллицу с ошибками — на сайте преподавателя русского это недопустимо.

## 4. Если кадр не понравился

- «Сделай свет мягче и холоднее, убери жёлтый оттенок».
- «Меньше предметов, больше пустого места».
- «Убери все надписи — корешки и страницы должны быть пустыми».
- «Камера ниже, почти на уровне стола».
