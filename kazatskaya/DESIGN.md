# Дизайн-тезис

**Идея: «тетрадь в клетку, на полях которой учитель ставит 100».**
Сайт — чистый лист голубой клетки (настоящая школьная тетрадь, а не абстрактный градиент), по нему проходят
пометки трёх «ручек»: синяя — текст и акценты, красная — оценка «100» на полях, зачёркивание ошибки и поля
тетради, зелёная — галочка «верно». Это язык, понятный и ученику, и родителю, и учителю, и он прямо
следует из предмета: Анна проверяет работы — сайт выглядит как проверенная работа.

- **Типографика.** Cormorant Garamond (кириллица, курсив) — литературный голос: крупные заголовки, цифры,
  курсивные акценты («сто», «проверьте»). Manrope — спокойный интерфейс и текст. Marck Script — рукописные
  пометки (имена учеников, «А кто здесь умничает?», подпись), строго дозированно.
- **Цвет.** Голубые и синие из брифа + тёплый `sand-100` из бежевого пиджака на фото (фон тренажёра, подложка
  фото) — чтобы холодная палитра не «воевала» с тёплой фотографией. Жёлтый маркер и красная ручка — меньше 3 %
  площади.
- **Ритм.** Светлая → тёмная («Результаты» — сердце страницы, navy с голубым свечением) → светлая → тёмный
  финал. Асимметрия: крупные цифры, ступенчатая сетка статистики, sticky-колонки.
- **Движение.** Скролл нативный — никакого перехвата колеса, пинов и параллакса. Одно спокойное интро на первом
  экране (строки заголовка, ручка обводит «100»), дальше — блоки один раз появляются при входе в экран
  (IntersectionObserver + CSS), маршрут дорисовывается, галочки дописываются, ошибка зачёркивается.
- **Без декора ради декора.** Убраны прелоадер, курсор, магнитные кнопки, блики, aurora-пятна, летающие буквы,
  стеклянные стикеры и бегущая строка: вместо них — фотографии (см. PHOTOS.md).

## Решения, которые я принял сам

1. **Astro вместо Next.js.** Сайт — одна статичная страница: Astro рендерит её из `content.ts` в чистый HTML
   без React-рантайма, первый экран не ждёт гидратации. JS — только GSAP + Lenis + сценарии (~61 КБ gzip).
2. **В ролике 8 выпускников, а не 4.** В видео подписаны Аня 100, Эмиль 92, Варя 100, Маша 97, Вика 98,
   Настя 91, Рома 91, Тая 96 — показаны все восемь (это данные самой Анны).
3. **Основная кнопка — `blue-600`, а не `blue-500`.** Белый текст на `#4F8EDB` даёт контраст 3,4 : 1, ниже AA;
   на `#3A74BF` — 4,7 : 1. `blue-500` остаётся акцентом (курсив, цифры, монограмма в фавиконе).
4. **Подсветка манифеста — цветом, а не прозрачностью**, чтобы стартовое состояние тоже проходило контраст.
5. **Отзывы.** Реальных текстов нет — в боевой сборке секция показывает только честную ссылку на канал;
   карточки-плейсхолдеры видны лишь в режиме редактуры.
